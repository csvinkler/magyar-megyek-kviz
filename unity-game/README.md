# Megyejaror Voxel

The Unity remake keeps the Hungarian county-navigation quiz and battle loop, with a bright block-built voxel look. It is a standalone Unity 6 project; the Godot prototype remains unchanged.

## Open and run

1. Install Unity Hub and Unity 6 (`6000.6.7f1`).
2. In Unity Hub, choose **Add > Add project from disk** and select `unity-game`.
3. Open `Assets/Scenes/VoxelPatrol.unity`, then press **Play**.

The initial scene is generated by the Unity Editor bootstrap if it does not exist yet. County shapes are built from the included CC0-derived county data at runtime; no downloaded art assets or extra packages are required.

To create a standalone Windows build, choose **Megyejaror > Build Windows Game** in the Unity Editor. The executable is written to `Build/Megyejaror.exe`.

## Controls

- Move: arrow keys or WASD.
- Confirm the county under the soldier / start the battle: Enter.
- Reach the named county before confirming. The map does not reveal the answer under the soldier.
- Correct choices win a short randomized voxel battle and turn the county green.
- Wrong choices start a different battle, cost one of three lives, and keep the current destination active. Three mistakes end the run.
- Missed counties are offered in a review round after the base round, while lives remain.

## Data

`Assets/Resources/counties.json` contains the 19 county boundaries, county seats, and names. It is derived from the repository's existing simplified geoBoundaries CC0 map data.
